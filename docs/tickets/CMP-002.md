---

## Priority

## Objective

Implement the first version of the Complaint API using FastAPI.

The API should allow authenticated users to create, retrieve, update, list, and soft-delete complaints.

No AI processing is included.

---

## Background

Database models are complete.

This ticket exposes the Complaint Engine through REST endpoints.

---

## Scope

Backend only.

Implement:

POST   /api/v1/complaints

GET    /api/v1/complaints

GET    /api/v1/complaints/{id}

PATCH  /api/v1/complaints/{id}

DELETE /api/v1/complaints/{id}

Implement:

- SQLAlchemy repositories
- Service layer
- FastAPI router
- Pydantic request/response schemas
- Dependency injection
- Proper HTTP status codes

Soft delete:

DELETE should populate deleted_at instead of removing rows.

Do not return deleted complaints.

---
