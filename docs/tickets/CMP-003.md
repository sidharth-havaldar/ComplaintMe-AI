## Objective

Implement the first Complaint Submission experience.

The user should only answer one question:

"Tell us what happened."

ComplaintMe AI should keep user effort to an absolute minimum.

---

## Background

The Complaint CRUD API already exists.

Authentication is complete.

This page becomes the primary experience after login.

---

## Scope

Frontend only.

Create:

frontend/src/app/dashboard/page.tsx

Implement:

- Large multiline text area
- "Tell us what happened." heading
- Optional attachment placeholder (no upload logic yet)
- "Analyze Complaint" button
- Loading state
- Friendly error handling
- Success redirect to the complaint detail page after creation

Use the existing Complaint API.

POST

/api/v1/complaints

Payload:

{
  "description": "..."
}

Do not send title.

Do not ask for category.

Do not ask for priority.

Do not ask for department.

---
