# PROJECT CONTEXT

## Project Name

ComplaintMe AI

---

## AI Framework

Cortexa

---

## Project Vision

ComplaintMe AI is an AI-powered Complaint Intelligence Platform.

Users submit complaints using natural language.

The Cortexa Intelligence Engine transforms those complaints into structured business intelligence.

---

## Product Philosophy

Instead of asking users to fill complicated complaint forms,

we ask only one question:

> Tell us what happened.

Everything else should be generated automatically by AI.

## Backend Principles

Controllers contain no business logic.

Business logic belongs inside Services.

Database queries belong inside Repositories.

AI logic belongs inside Cortexa.

---

## Cortexa Modules

- Complaint Classification
- Entity Recognition
- Sentiment Analysis
- Priority Detection
- Expectation Extraction
- Summary Generation

---

## Development Rules

Never generate demo code.

Always generate production-quality code.

Always explain architecture decisions.

Always stop after completing the requested module.

Never build future modules until requested.

Never over-engineer.

No microservices.

No Kafka.

No RabbitMQ.

No Celery.

No Kubernetes.

Build as a modular monolith.

---

## Goal

This project should be production-ready and capable of becoming an enterprise AI platform in future.
